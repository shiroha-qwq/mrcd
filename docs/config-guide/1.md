# 运行要求

- Node.js 22+
- pnpm（如果没安装则运行`npm install -g pnpm`）
- git
- 较新版本的Edge/Chrome/Firefox/Safari

# 克隆仓库到本地

在本地运行: 

```bash
git clone https://github.com/Miralous/Miracle.git
```

进入博客目录:

```bash
cd Miracle
```

## 清理目录

请将以下目录的所有文件删除

```
.
├─ public
│  └─data
|    ├─friends
|    ├─moments
|    └─photos 
└─ src
   └─posts
```

::: warning
请不要使用`pnpm clean`，此脚本已过时
:::

## 安装依赖

在目录下运行:

```bash
pnpm install
```

## 测试

运行
```bash
pnpm dev
```

访问 `localhost:4321` 检查


# 更新

在目录下运行命令:

```bash
git pull
```
