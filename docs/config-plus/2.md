# 新建留言文件

在`./public/data/moments`下新建`YYMMDD-XXX.yaml`

::: tip
`YYMMDD-XXX.yaml`前面的`YYMMDD-XXX`需要替换成实际内容（如260814-test.yaml）
:::

格式必须严格为以下模板:

```yaml
date: YYYY-MM-DD
time: XX:XX
image: test
content: test
```

`date` 留言日期（必填）

`time` 留言时间（必填）

`image` 留言图片（可选）

`content` 留言内容（必填）

::: warning
`date` `time` `content`等都要替换为实际内容
:::
