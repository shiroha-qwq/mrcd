# 新建友链文件

在`./public/data/friends`下新建`name.json`

::: tip
`name.json`中的`name`需要替换成友链的名字
:::

格式必须严格为以下格式：

```json
{
  "title": "name",
  "link": "link",
  "desc": "des",
  "img": "img"
}
```

`title` 友链名称

`link` 友链网址

`desc` 友链简介

`img` 友链图标

::: tip
模板中的 `title` `link` `desc` `img` 四个字段需替换为友链的实际信息
:::
